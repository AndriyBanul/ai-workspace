# Definition of Done

A task is done only when:

- The implementation is complete.
- Relevant tests are added or updated.
- Existing tests pass, when runnable.
- Documentation is updated if behavior, architecture, setup, or operational expectations changed.
- The change is committed to the correct branch when a commit is requested.
- Trade-offs, limitations, and any skipped verification are clearly reported.

Do not treat code generation alone as completion.

If tests or verification cannot be run, explain why and describe the remaining risk.
