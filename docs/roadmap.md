# Roadmap

The platform should eventually support:

- RAG.
- OCR.
- Speech-to-Text.
- Text-to-Speech.
- Vision.
- Video understanding.
- Agent orchestration.
- Enterprise integrations.
- Workflow automation.
- Knowledge Graph.
- Multi-agent collaboration.

## Future Infrastructure

- Kafka.
- Redis.
- Kubernetes.
- OpenSearch.
- Vector Database.
- Object Storage.

These technologies should be introduced when they solve concrete product or operational needs, not before.
