`simple.doc` is an Apache POI binary Word test fixture, downloaded from
https://raw.githubusercontent.com/apache/poi/trunk/test-data/document/simple.doc
on 2026-09-14. Apache POI is licensed under the Apache License, Version 2.0:
https://www.apache.org/licenses/LICENSE-2.0

The fixture is kept locally so legacy DOC extraction tests run offline.
XLS and PPT test documents are generated in memory with Apache POI.
